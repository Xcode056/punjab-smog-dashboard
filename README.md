# Punjab Smog & Fog Dashboard

A lightweight, mobile-friendly dashboard for checking air quality across selected cities in Punjab, Pakistan.

## Features

- Live air-quality information using the Open-Meteo Air Quality API
- City selection for supported Punjab cities
- AQI and PM2.5 readings
- Colour-coded hourly AQI forecast
- Identification of the best available hours based on forecast PM2.5
- Tomorrow's forecast
- Health advice based on air-quality levels
- Urdu and English language support
- Urdu Nastaliq font support
- AQI analytics chart
- WhatsApp sharing functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo Air Quality API
- HTML Canvas

## Data Source

Air-quality data is retrieved from the [Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api).

Forecasts are estimates and may differ from actual conditions. This dashboard is for informational purposes only and is not a substitute for official public-health advice.

## Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Run `index.html` using the Live Server extension.

## Deployment

This project can be deployed using GitHub Pages.
