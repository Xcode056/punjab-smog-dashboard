# Launch Fixes

I made a few improvements to the Punjab Smog & Fog Dashboard before launch.

- Fixed the WhatsApp sharing process so it doesn't open an unnecessary blank tab.
- Improved image sharing on Android so users can share the air-quality card through WhatsApp.
- Fixed the AQI badge colours so they match the actual air-quality level.
- Fixed the date and time display on the Urdu sharing card.
- Replaced the large Open Graph image with a smaller, optimized image to make link previews load faster.
- Updated the website links and sharing URLs to use dhund.pk.

These changes make the dashboard easier to use and improve its sharing experience.
